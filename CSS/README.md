# DOG PAW NPO Website

## About the Project

The DOG PAW website is a responsive website created for a non-profit
organisation that supports dogs and their owners who may struggle
to afford essential dog care.

The website provides information about DOG PAW, its services,
how people can get help, and ways to support the organisation.
